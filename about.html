About this tracker

A free, live, single-page tracker of the vendors and software affected by the PHP2Shell remote-code-execution vulnerabilities CVE-2026-109618 and CVE-2026-109619, fixed upstream in PHP 8.2.35 / 8.3.36 / 8.4.27 / 8.5.12.

What PHP2Shell is

PHP2Shell is a pair of remote-code-execution flaws in the way PHP handles web requests. The exposed surface is the web request handlers — PHP-FPM, Apache with mod_php, php-cgi and LiteSpeed among them — so a site served by an affected PHP runtime is in scope until it is upgraded. Moving to a fixed PHP release is the remedy.

The three views

  • Actionable — only entries that are Vulnerable or have a Fix for either CVE: the rows worth acting on first.
  • Full list — the complete inventory, every status, including investigation leads.
  • Index A–Z — a directory of every supplier, with product counts, a status mix, and a link to the supplier’s page in the source.

In any view you can search by vendor or product and filter by status.

Live data, and an offline build

On every open the page fetches the list live from the NCSC-NL php2shell repository and rebuilds all views, so it is current each time it loads. If the live fetch is blocked it falls back to an embedded snapshot. A single-file offline build that makes no network requests is available for air-gapped environments or networks where GitHub is blocked.

Reading the data

Status is shown per CVE; it is the same for CVE-2026-109618 and -109619 for almost every entry, and where it differs both are shown. The Source column lists every link the source cites for a row — human and advisory pages first, raw code files last — and each link shows its full URL on hover. Entries are investigation leads until the vendor confirms: always check the vendor’s own advisory before acting.

Security & privacy

This is a static page with no backend, no cookies, no analytics and no tracking of any kind. It is hardened with a strict Content-Security-Policy, all data is HTML-escaped, and source links are restricted to http(s). The offline build makes no network requests at all.
